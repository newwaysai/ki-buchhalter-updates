# ki-buchhalter-updates

Versions-Endpoint für den **KI-Buchhalter (Bruno)™** von [newways.ai](https://newways.ai).

- [`version.json`](version.json) — maschinenlesbar, wird von Brunos „Update prüfen" (Modus 14) gelesen. Nur auf explizite Nutzer-Aktion, kein automatischer Abruf.
- [`CHANGELOG.md`](CHANGELOG.md) — menschenlesbar: was ist in welcher Version neu.

**Hier liegen keine Update-Pakete und kein Produkt-Code.** Updates erhalten lizenzierte Käufer per E-Mail (mit SHA256-Prüfcode). Interesse am Produkt: [newways.ai](https://newways.ai).
